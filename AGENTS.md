# AGENTS.md

## Именование файлов
- md-файл записи всегда в английском наименовании: latin, нижний регистр,
  слова через дефис (например `shutter-island.md`, `the-quintessential-quintuplets.md`).
- Предпочтительно оригинальное/английское название произведения.

## Сомнения
- Если не можешь найти/подобрать подходящий entity, не уверен в названии, частях
  или переводах — задай вопрос пользователю, прежде чем создавать запись.
- Перед добавлением записи всегда спрашивай пользователя, нужно ли указать `added_by`.

## Структура записи
- Одна запись = один файл `entities/<category>/<slug>.md`.
- Обязателен только `title` (по-русски, как даёт пользователь).
- `tags` — опциональный массив уникальных строк `[a-zа-яё0-9-]+`.
- `parts` — опциональный массив названий частей цикла
  (movies, books, games, anime, manga). Непустой, без повторов.
- `added_by` — опциональная ссылка на `id` пользователя из `users.yaml`
  (не имя). Список пользователей хранит `id` и `name`.
- Поля, отсутствующие в `schemas/<category>.schema.json`, не добавлять.

## Проверка
- После изменений: `python scripts/validate.py`
  (зависимости: `pip install -r requirements-dev.txt`).
- Названия внутри категории не должны повторяться.
- `added_by` должен ссылаться на существующий `id` из `users.yaml`.
- Менять схемы/категории/README — только по запросу пользователя.
